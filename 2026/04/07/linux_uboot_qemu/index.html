前言

最终结果

问题及解决方法：

  1. target ABI仅有EABI

​ 需要勾选Enable VFP extension support

  1. buildroot编译，无法寻找linux源码位置，显示linux-HEAD 404

    kernel–>kernel version–>custom version

    buildroot根目录创建local.mk，打开后填写

    此方法会让 Buildroot 使用 rsync 同步源码变更，而非重新解压 tar 包，适合频繁修改内核源码的场景

  2. buildroot编译，Can’t find default configuration “arch/arm/configs/vexpress_defconfig_defconfig”

    Defconfig name无需填写全名，只填vexpress

  3. buildroot编译，没有规则可制作目标“arch/arm/boot/dts/arm/vexpress-v2p-ca9.dtb.dtb

    dts也无需写全名，只填vexpress-v2p-ca9
